## 무엇을 바꿨는가

3.0.3 tag 78cabd44f2ba8b50c1b91a3e8b2eb168508b205f의 별도 작업본에서 시작했다. 4.0.3의 연결·Obsidian 호환성·저장 기반과 최신 연결의 오류·취소 처리를 선택적으로 가져왔다. 등급은 코드가 선택하고 질문 유형과 렌즈는 모델이 선택하는 원형 구조를 유지한다. 팩 전체를 한 번에 요청한다.

분야·사고 성향 가중치·난도·등급은 간단한 선호 정보로 전달한다. 수치는 완성 문항에서 측정한 사고량이 아니다. 자동 AI 채점·재생성·레시피·다중 실험 라우터를 넣지 않는다.

기존 직접 입력 프롬프트는 유지하고 설정 사용/직접 입력을 명시적으로 선택한다. 질문을 먼저 보여주고 도움말은 접는다. 보관 카드에 원래 도움말을 저장하여 마크다운 승격 때도 유지한다. 실패한 팩은 빈 카드로 채우지 않으며 이전 팩을 남긴다.

## 검사와 수정 이력

1. 기존 연결·저장 회귀 113개와 이번 설정·단일 호출·오류·취소·도움말 저장 검사 6개 통과.
2. 실제 4모델×2조건 8팩40장 반환, 8회 모델 요청, 평가모델0회. 원래 도움말 생성량 때문에 25–123초가 걸렸다.
3. 전역 require로 Obsidian 모듈을 불러오는 UI 준비가 실패했다. 임시 QA 플러그인의 정상 Obsidian 로더로 바꿔 실제 컴포넌트를 확인했다. 실패 때 캡처한 구버전 화면은 성공 증거에서 제외했다.
4. 전설 글로우 애니메이션이 등장 애니메이션을 덮어 카드가 투명하게 남는 오류를 고쳤다. 기본 상태를 불투명하게 두어 애니메이션이 없어도 보인다. hidden 속성보다 버튼 스타일이 우선하여 취소 버튼이 보이던 오류도 수정했다.
5. 설정을 생성 뒤 접고, 390px 화면에서 설정 끝과 카드에 접근 가능한지 확인했다.
6. 숨은 측정용 select가 UI 검사에 잡힌 오탐은 aria-hidden을 제외하여 재확인했다. 제품 기준을 완화한 것이 아니다.
7. 설치 전 플러그인 파일·설정과 열린 문서 초안을 private backup/save/hash로 보존했다. 네이티브 실제 Sonnet1팩, 보관·재열기·Markdown 내보내기를 확인했다. 옛 OAuth는 복원하지 않았다.

## 한계

과거 생성 실패·낮은 사람 점수는 이 검증으로 해소되지 않는다. 이번 출시는 기능·편의 업데이트이며 심리측정 모델이나 교육효과의 검증이 아니다. 사용자 최신 반응은 전설 질문이 그럴듯해 보인다는 정성 의견이며 전체 품질 승인이 아니다. Gemini 및 실기기 모바일 연결, 모델/강도 전수 조합은 새로 검사하지 않았다.

개발 실행 에이전트는 Codex이며 이 세션의 정확한 내부 모델 식별자와 추론 강도는 노출된 실행 정보만으로 확인하지 못했다. 생성 모델·강도는 QA 문서와 원시 실행 기록에 명시했다. 비공개 추론 과정을 개발 로그로 꾸미지 않는다.
